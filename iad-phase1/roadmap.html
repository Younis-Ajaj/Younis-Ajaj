Learning Roadmap

Six ordered stages take you from zero to a deployable AI project. Finish each stage project before moving on.

How the roadmap works

  1. Start at Stage 1 even if you know some Python — skim what you know.
  2. Study the topics using the matching resources in the library.
  3. Build the stage project and push it to GitHub.
  4. Share it at a study circle on the events page for feedback.

Estimated total time

27–29 weeks at about 8 hours per week — roughly two university semesters alongside your courses.

Times are estimates for a second-year student and will vary.

The six stages

Each stage lists its key topics, level, expected duration and a portfolio project.

  1. Stage 1: Programming Foundations

    Beginner · 3–4 weeks
    • Python syntax, data types and control flow
    • Functions, modules and virtual environments
    • Git & GitHub basics

    Stage project: Command-line expense tracker

  2. Stage 2: Mathematics & Statistics

    Beginner · 4–5 weeks
    • Linear algebra: vectors, matrices, dot products
    • Calculus: derivatives and gradients
    • Probability, distributions and hypothesis testing

    Stage project: A/B test analysis report

  3. Stage 3: Data Analysis & Visualisation

    Intermediate · 4 weeks
    • NumPy and Pandas for cleaning and reshaping
    • SQL queries and joins
    • Matplotlib / Seaborn storytelling

    Stage project: Exploratory analysis of an open Jordanian dataset

  4. Stage 4: Machine Learning

    Intermediate · 6 weeks
    • Supervised learning: regression & classification
    • Model evaluation, cross-validation, overfitting
    • scikit-learn pipelines

    Stage project: House-price prediction model

  5. Stage 5: Deep Learning & NLP

    Advanced · 6 weeks
    • Neural networks with PyTorch
    • CNNs for images, Transformers for text
    • Using pre-trained models and fine-tuning

    Stage project: Arabic sentiment classifier

  6. Stage 6: MLOps & Cloud Deployment

    Advanced · 4 weeks
    • Packaging models as REST APIs
    • Docker, CI/CD and experiment tracking
    • Deploying on a cloud platform

    Stage project: Deployed prediction web service
