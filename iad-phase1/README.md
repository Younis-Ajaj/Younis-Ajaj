# DataPath Jordan — Phase I (HTML/CSS Prototype)

Internet Applications Development (1) · 03003202 · Al-Ahliyya Amman University · 2026/2027 First Semester

A static website that gives Data Science & AI students one organised place to learn: a six-stage roadmap, a free resource library, an events schedule and a registration form.

## How to run
Open `index.html` in any browser. No server, build step or internet connection is needed.

## Structure
| File | Purpose |
|---|---|
| `index.html` | Home page |
| `roadmap.html` | Six-stage learning roadmap |
| `resources.html` | Resource library and datasets table |
| `events.html` | Event schedule table |
| `about.html` | Mission, values, team |
| `contact.html` | Registration form, contact details, FAQ |
| `css/style.css` | One shared stylesheet (Grid, Flexbox, media queries) |
| `images/` | Original SVG logo, illustration, icons, avatars |
| `report/` | Phase I Word report (+ PDF copy and screenshots) |

## Phase I scope
HTML and CSS only. The mobile menu works with CSS alone (checkbox toggle). Form validation, filtering and other interaction come in Phase II (JavaScript).
